# سوغات‌یار 🧡

نرم‌افزار اندروید مدیریت فروش خشکبار و زعفران به‌صورت نقد، نسیه و اقساطی — مخصوص فروش به آشنایان و دوستان.

ساخته‌شده برای: **یوسف (SoftwareTrain)**

---

## امکانات

- **دفتر مشتری:** مانده حساب هر مشتری، برچسب‌ها (همکار، خوش‌حساب، فامیل…)، تماس/پیامک/واتس‌اپ مستقیم، افزودن از مخاطبین گوشی.
- **فروش سریع:** انتخاب کالا با افزودن/کم‌کردن، سه حالت پرداخت نقد / نسیه / اقساط.
- **اقساط هوشمند:** جدول اقساط ماهانه خودکار از مبلغ باقی‌مانده ساخته می‌شود؛ هر قسط به نزدیک‌ترین هزار تومان گرد و باقی‌مانده به قسط آخر اضافه می‌شود. ثبت پرداخت هر قسط با یک لمس.
- **پیش‌بینی سفارش بعدی:** بر اساس فاصله خریدهای قبلی حدس می‌زند کی مشتری دوباره سفارش می‌دهد و در «کارهای امروز» یادآوری می‌کند.
- **اعلام گروهی:** قالب‌های آماده (جنس جدید، تخفیف، یادآوری مانده، تبریک) + انتخاب گروه گیرنده (همه / بدهکارها / ۶۰ روز خرید نکرده) + جای‌گذاری خودکار نام هر نفر با `{نام}`.
- **ارسال از سیم‌کارت گوشی:** پیامک مستقیم از سیم‌کارت خودت (بدون پنل و هزینه پنل). واتس‌اپ/تلگرام/ایتا هم با باز شدن اپ پشتیبانی می‌شود.
- **کالا و موجودی:** قیمت خرید/فروش، سود هر قلم، و هشدار کم‌شدن موجودی (مثلاً قبل از یلدا).
- **پشتیبان‌گیری و خروجی:** فایل پشتیبان JSON و خروجی CSV از مانده حساب‌ها (مناسب باز شدن در اکسل).
- **آفلاین و فارسی:** همه‌چیز روی گوشی، دیتابیس محلی (Room)، تاریخ شمسی، راست‌به‌چپ.

## ساخت فایل APK

### راه ۱ — Android Studio (ساده‌ترین)
1. پوشه پروژه را در **Android Studio** باز کن (Open → این پوشه).
2. صبر کن تا Gradle همگام‌سازی و کتابخانه‌ها دانلود شوند (نیاز به اینترنت).
3. منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. فایل در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

### راه ۲ — خط فرمان
```bash
./gradlew assembleDebug
```
APK در `app/build/outputs/apk/debug/app-debug.apk`.

### راه ۳ — GitHub Actions (ساخت ابری)
پروژه را روی یک ریپوی گیت‌هاب پوش کن؛ ورک‌فلو `.github/workflows/build-apk.yml` به‌صورت خودکار APK را می‌سازد. از بخش **Actions → آخرین اجرا → Artifacts** فایل `soghatyar-debug-apk` را دانلود کن.

## نصب روی گوشی
فایل `app-debug.apk` را روی گوشی کپی و نصب کن (نصب از منابع نامشخص را فعال کن). این نسخه debug است و برای استفاده شخصی مناسب است؛ برای انتشار در بازار/مایکت باید نسخه release امضا شود.

## مجوزها
- **ارسال پیامک (SEND_SMS):** برای ارسال مستقیم اعلام‌ها از سیم‌کارت.
- **خواندن مخاطبین (READ_CONTACTS):** برای افزودن سریع مشتری از دفترچه تلفن.
هر دو هنگام اولین استفاده از کاربر پرسیده می‌شوند.
